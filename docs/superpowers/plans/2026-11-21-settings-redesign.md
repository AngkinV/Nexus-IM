## 一、布局原则（按你的要求）

参考稿最外层是：

```
w-full max-w-[1020px] h-[700px] rounded-2xl border shadow-[...] backdrop-blur-xl
```

**这个 1020×700 的圆角框是展示用的画布，不实现。** 我们的设置页要铺满整个应用窗口，
去掉 `max-w`、去掉 `h-[700px]`、去掉 `rounded-2xl`、去掉 `border`、去掉 `shadow`。

保留的结构：

```
┌─────────────────────────────────────────────────────────────┐
│ header 48px   ← 返回 · 面包屑 · 版本 · 搜索 · 恢复默认        │
├──────────────┬──────────────────────────────────────────────┤
│ 左侧导航      │ 右侧内容区（独立滚动）                        │
│ 256px        │ flex-1                                       │
│              │                                              │
│ 偏好设置分类   │  ▸ 分区标题 + 英文副标题 ─────────────        │
│ · 通用与界面   │    ┌────────┬────────┐                       │
│ · 桌面宠物&3D  │    │ 卡片   │ 卡片   │                       │
│ · 消息与通知   │    └────────┴────────┘                       │
│ · 角色与模型   │                                              │
│ · 快捷键与更新 │  ▸ 下一个分区 ...                            │
│              │                                              │
│ ─────────    │                                              │
│ GPU/显存状态  │                                              │
│ 退出当前登录  │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- header 48px 全宽，作为 Electron 拖拽区（`-webkit-app-region: drag`），内部按钮设 `no-drag`
- 左侧 256px 固定，背景 `#0e0e11`，右边框 `1px solid rgba(255,255,255,.08)`
- 右侧内容区 `flex-1` 独立滚动，背景 `#131316`
- 内容区左右 padding 24px，上下 24px
- **不套居中框**，全窗口铺满

## 二、功能分档

参考稿 16 项设置，我们后端实际支持的只有 6 项。分三档处理：

### A 档：现在就能真实现（本轮做）

| 设置项 | 现有支撑 | 要做的事 |
|---|---|---|
| 应用界面语言 | `locales/i18n.js`，已有 zh/en | 照设计稿做成下拉，只列 zh/en（不列日文/繁体，因为没语言包） |
| 桌面宠物开关 | `companionStore.petVisible`，存 localStorage，真影响 3D 加载 | 直接接上 |
| 角色与模型偏好 | `RoleSettingsPanel` 已有完整面板 | 从弹窗改成内联卡片，点「切换预设」展开面板 |
| 隐私设置 | `userAPI.updatePrivacySettings`，后端真有 | 从弹窗改成内联卡片（4 个开关 + 好友验证模式） |
| 检查更新 | Electron `electronAPI`，真有 | 直接接上 |
| 退出登录 | 真有 | 直接接上 |

### B 档：设计稿有、我们能做但要新写逻辑（需你确认后做）

| 设置项 | 可行性 | 需要做的事 |
|---|---|---|
| 桌面系统级通知开关 | **能做，而且必须做** | 现在的通知开关是假的（`ref(true)` 没人读）。`websocket.js:324` 和 `call.js:214` 直接调 `electronAPI.showNotification`，不看任何设置。要新增 `settings` store，两处调用前先检查开关 |
| 快捷键展示 | 能做（只读展示） | `Main.vue` 已有 ⌘K（命令面板）。⌘, 打开设置需要新增。ESC 返回已有。做成只读列表，标真实键位 |
| GPU / 显存实时状态 | 能做 | Electron 主进程读 `process.getGPUInfo` / `app.getAppMetrics()`，通过 IPC 给渲染进程。只在 Electron 下显示 |
| 时间显示格式（12/24 小时） | 能做 | 新增格式化工具，消息时间戳统一走它。改动面较大（所有时间显示点） |

### C 档：我们没这个功能，不做（避免摆假控件）

| 设计稿的项 | 为什么不做 |
|---|---|
| 超感毛玻璃透明度（iOS 27） | 纯装饰概念，无对应实现 |
| 视窗缩放与字体微调 | 需要全局 zoom 机制，影响所有页面布局，风险高 |
| 渲染帧率上限（30/60 FPS） | 现有 3D 用 requestAnimationFrame 默认 60，加限帧要改渲染循环，收益低 |
| 视口渲染分辨率（720p/1080p/Native） | 同上，需改 renderer 尺寸 |
| 后台失焦智能挂起 | 需监听窗口焦点并暂停 WebGL，可以做但优先级低 |
| 触感与极简音效 | 没有音效资源，也没触感（桌面端无） |
| 程序坞/托盘角标 | Electron 未实现 badge，且 macOS 需 dock API |
| 本地端加密存储（AES-256） | 后端无此功能 |
| 清空缓存 | 无缓存管理机制 |

**C 档一律不摆**，界面上不出现。

## 五、需要你决定的 4 件事

1. **B 档做不做？** 我建议至少做「桌面系统级通知开关」——因为现在这个开关是假的，
   摆在界面上就是骗人。做了它才名副其实。其余三项（GPU 状态、快捷键展示、12/24 小时）可分批。

2. **左侧导航几项？** 设计稿 7 项，但「隐私安全 & 本地存储」和「检查更新与关于」在参考稿里
   没有对应内容分区。我建议按上面 5 个分区做 5 项导航，一一对应，点哪项滚到哪。

3. **header 要不要？** 设计稿 header 有「返回会话 / NEXUS-IM / 偏好设置 / 版本 / 搜索 / 恢复默认」。
   搜索框和「恢复默认」我们没有对应功能。建议 header 只保留：返回按钮 + 面包屑 + 版本号，
   去掉搜索和恢复默认。

4. **角色与模型 / 隐私设置** 现在是弹窗，改成内联卡片会动到 `RoleSettingsPanel.vue` 的调用方式。
   要改成内联，还是保持弹窗只是换个入口样式？
