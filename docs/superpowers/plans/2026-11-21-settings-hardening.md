## 实现规则

### 1. 账号与保存

- 设置内存、磁盘桶、加密密钥、等待的写入与网络响应绑定明确账号。
- 账号切换立即冻结编辑并失效旧网络上下文，待旧账号快照落盘后加载新账号。
- 不把没有归属的旧全局设置或旧桌宠开关分配给新账号。
- 设置页先通过真实后端 profile 验证身份；失败时只读，提供重试。不能凭本地占位 token 编辑。
- 时间格式、毛玻璃强度、消息/操作提示音跟随账号保存到 Java。语言及设备性能偏好保存在本机，按账号隔离。
- 600ms 内的多个字段合并为一份请求。响应必须符合真实 DTO 契约，并逐字段确认后清除待同步标记。
- 本地待同步字段保存在磁盘；离线/5xx 后重试。400 等永久客户端错误不盲重试。
- GET 使用请求序号与字段修改版本，不能覆盖其发起后的编辑或已成功保存的新值。
- 各账号的在途 PUT 独立；旧账号 finally 和迟到的 401 不影响新账号。退出等待已有保存，超时仍保留待同步数据。
- 存储配额/加密失败有明确反馈，不虚报已保存。

### 2. 本地加密

- 加密开关与账号交接共用串行屏障，操作期间不可编辑。
- AES-GCM v2 附带账号关联的附加认证数据；只有显式账号的密钥用于读写。
- 不再自动尝试没有可靠归属的旧共享密钥。旧的独立账号密文可读取并在下一次写入升级。
- 新格式写入后读回精确内容，才报告成功；验证失败恢复原始字节。
- 无法解密时保留原文，使用默认值并阻止覆盖。只有验证登录后的明确确认，才丢弃并重新开始。
- 它是本机静态设置加密，不是聊天端到端加密，也不抵抗恶意同源代码或本机执行权限。

### 3. 后端与隐私

- 偏好使用独立事务重试首次唯一键插入，并只更新变化列。
- 401/403、校验 400、存储不可用 503、意外错误 500 区分，返回不泄露内部数据库细节。
- profile 返回好友申请方式；前端等待完整读取再允许编辑。
- 隐私提交仅包含实际改动字段，实体使用动态更新，避免不同窗口改不同字段互相还原。
- 非法好友申请方式被拒绝，不再自动降级为更宽松的 DIRECT。
- 隐私读取、保存和确认框都有账号/会话与乱序保护。

### 4. 用户模型与动作

- 预置资源只读；用户上传文件与元数据写入 Java 的独立账号目录，不写前端 public/dist。
- 私有库接口统一位于 `/api/companion/user-assets`，所有权从真实认证 principal 取得。
- 文件读取需鉴权、禁止公共缓存；文件 ID 稳定，重命名显示名不破坏角色绑定。
- 上传检查类型、大小、VRM 容器与内嵌资源；拒绝路径穿越。
- 模型绑定仍写既有角色接口，并校验真实返回；所有初始化、刷新、修改的消费者不再套用旧本地 model override。
- 模型/动作读取失败与空库区分，不能拿本地旧数据冒充后端返回。
- 上传、重命名、删除全程携带起始账号/会话/角色；卸载或切账号后停止后续绑定、偏好写入和全局事件。
- 请求派发时再次核对身份；上传使用 multipart。
- 桌宠与模型舞台使用同一私有下载规则，认证信息只发给同一后端的私有资产路径，不发给外部模型 URL。
- 动作选择按账号记录；桌宠关闭时可记住选择，再开启恢复。离线资源加载失败不删除已记住的用户选择。

### 5. 真实消费者与界面

- `renderGovernor` 统一帧率、窗口质量和暂停；不保留三份旧调度模块。
- 帧率门控处理浮点误差；动画使用实际 delta，暂停后不一次补算后台时间。
- 质量按窗口物理高度比例应用到实际画布；窗口已小于目标时明确提示与原生相同。过渡动画在开始时采用档位。
- 原生焦点初始读取与事件顺序保护；失焦 30 秒暂停，关闭立即恢复，最小化始终停止连续绘制。
- 调度器在热更新/不同缓存 URL 下保持一个实例，避免设置与焦点监听分裂。
- 未读采用 chat store 的真实总数；新会话入站只计一次，自己的消息不算未读。
- 角标监听在应用根常驻，离开设置仍更新，退出清零。
- 声音来自真实入站、发送确认/失败与手动试听；未实现的触感功能不伪装为可用。
- 时间格式接入工作台历史和会话消费者。
- 七项导航对应七个锚点；点击高亮保留至用户主动滚动。
- 搜索隐藏不匹配控件，键盘也不能操作它们。交接/保存时非原生控件同样 inert。
- 内存显示实际进程 RAM 与真实系统容量，不冒充 VRAM；峰值为采样的同时总量。
- 缓存数字只统计可验证的 HTTP 缓存，清理保留登录存储、设置与密钥；清理范围如有失败明确反馈。
- 检查更新区分成功无更新与请求失败。
- 原生菜单实际跟随语言，非 macOS 保留窗口控制；返回有应用内兜底。
- macOS 原生按钮安全区随缩放保持物理宽度。
- 恢复默认仅恢复界面、通知与渲染偏好，不破坏语言、加密、角色绑定和隐私业务数据。

## 补充：现有真实登录的在线验证（已完成）

复用用户已经启动的 Java 与 5173 前端，预览中的登录得到真实受保护接口 200：

- 设置 GET 200，页面“已同步”，待同步字段为 0。
- 同时改变时间格式、毛玻璃、提示音，服务端再次 GET 与三项新值完全一致；随后立即还原，服务端及页面再次确认原值、“已同步”、待同步 0。
- 非法时间格式返回 400；以当前登录访问另一个用户的偏好返回 403，没有读取对方数据。
- 隐私只测试收紧已有公开权限（不开放原本关闭的手机/邮箱权限）；保存与回读一致，之后验证全部四个布尔项和好友申请方式恢复原值。
- 真实角色模型绑定更新后再次读取角色列表，URL 与模型类型一致；随后还原原始绑定并再次确认。
- 用户模型库、动作库接口均返回 200。
- 临时上传真实 FBX，后端用户库出现对应 owned 记录，私有文件读取成功，SHA-256 与原始文件一致；匿名读取返回 403。
- 该临时动作重命名真实落盘，稳定文件 URL 不变；最终通过删除接口清理，后端列表不再含测试记录。所有测试上传均已删除。
- 页面重载后仍保持真实登录、已同步、待同步 0，界面三项值与服务端一致，隐私可读取。

本轮没有遗留对用户偏好、隐私或角色模型的测试改动。用户自己启动的服务保留运行；独立测试窗口与测试服务器均已关闭，测试副本、日志和 profile 已清理。
