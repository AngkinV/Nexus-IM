# 聊天读取范围

工作台输入框下方，读取范围按钮紧挨关联知识库左侧。它用于指定下一次请求可以读取的其他聊天，不是群发入口，也不会自动把全部聊天记录发送给模型。

## 使用

1. 点击「聊天读取范围」，加载范围与可选对象。
2. 搜索并勾选联系人或群组，可多选。联系人对应你与该联系人的私聊，群组对应你有真实成员权限的群聊。
3. 选择时间范围。最近24小时、本周（所选时区周一零点至点击时刻）、全部时间，以及自定义起止均可使用。
4. 点击「确认下一次请求」，再在输入框发送具体的读取、检索或总结任务。

「进入群聊」是独立操作，不会改变勾选或确认。已选但不在最新资源列表里的对象仍显示类型与 ID，不会被静默丢弃。

## 确认与默认范围

- 本地选择、确认都不是服务器授权。每次请求仍由 Java 检查真实权限，Python 继续验证相同的授权范围。
- 确认只用于下一次请求。对象、时间、时区或重新加载发生变化后，需要重新确认。
- 「保存默认范围」只保存到当前工作台会话；保存会消耗本次确认，发送前必须重新确认。保存失败也不会偷偷恢复确认。
- 关闭、点击面板外部和 Esc 只收起面板，不保存、不确认、不清空选择。
- 未选对象时没有其他聊天的读取权限，普通问答仍可发送。

## 时间

自定义日期和时间按所选 IANA 时区解读，自动转换为后端现有的 UTC ISO `Z` 格式。开始包含在内，结束不包含在内；单边留空表示该边不限，两边留空表示全部时间。

起点必须早于终点；不存在或重复的夏令时时间会被拒绝，不静默选择偏移。恰好在周一起点点击「本周」时，会提示尚无时间区间，不扩展到未来一秒。

快捷项生成的是点击时刻的固定边界。保存后不会随着时钟或下一周自动滚动；面板始终显示具体起止时间，需重新点击快捷项才能更新。

## 展示与状态

- 桌面向按钮上方展开约420px浮层，最大高度720px且不超出工作台可用空间；默认正文滚动、标题与操作区保留。很矮的窗口改为整面板可滚动，避免操作被裁切。
- 窄屏使用挂到页面根部的底部面板，避开祖先容器的裁切和变换。按钮与知识库保持同排，紧凑状态仍有完整可访问文本。
- 搜索只过滤已加载的真实资源，不声称提供远程全库搜索。
- 加载（含创建会话阶段）、保存、切换、提交及运行期间冻结可变操作；旧请求返回不会写到新会话或账号。
- 服务器范围回执与高级版本信息分区折叠。回执仅表示获准范围，不代表已经读完全部记录；历史回执不是当前权限。
- 保持工作台黑白灰与统一字段样式，不使用参考稿的彩色授权徽章、成员数、部门或网关假状态。
